# Isometric-picture-book grammar

Upstream isometric-picture-book grammar distilled for new subjects. Original upstream MIT attribution remains necessary if text/code is copied or adapted more substantially.

## Meaning before scene

A clean, continuous place embodies a rule. Objects/figures act in the order a learner must understand. The design question is "what action or arrangement shows the invariant, sequence, category or change?", not "what pretty isometric setting can I depict?" One real place can depict a production sequence, biological relationship or route if the action, arrangement and labels make it true.

## Visual invariants

- **True iso:** world x/y project down-left/down-right at ~30°; z upright; no rotatable perspective camera. Camera translates and gently zooms only, usually 6–8%. Coordinates, annotations, text and view use one world→screen model.
- **Full bleed:** no outer picture frame, floating platform or inset cards. Ground extends off frame. Real places are plausible sized, cut low if a wall would obscure actors. A long single street/yard can be one place across stages.
- **Flat three tones:** each colour top toward warm paper, +y face base, +x face warm umber. Curvature can use coarse same-tone facets. No outlines, gradients, shadows, textures, glow or glossy sphere glints. Props simpler than the teaching actors.
- **Palette:** paper; dark ink; one persimmon-like rule accent; one calmer subject colour; a distinct functional marking colour; where needed four restrained muted clothing colours. No colour solely decorates.
- **People, if needed:** faceless back-view with head/back torso/legs shoes, feet anchored. Movement is calm, meaningful, deterministic and interpolated. At the final size, no bodies through walls/furniture or other people. No dramatized gestures.
- **Ground typography:** open-licensed book serif CJK/Latin, one short phrase per beat, one accent character or number meaning the rule. Long teaching goes to VO, not a floor paragraph. Clear area at least 5% inside frame, separate lower subtitle lane.

## Native teaching moves

| Move | Use in general |
|---|---|
| Floor phrase | short category, ordinal, variable label near (not on) subject |
| Ordered movement | actors see when they may go next; an explanation is the order |
| Order light | intended positions/stages illuminate before motion |
| Accent arrow ground channel | cause, path, next unit; good if aligned to world axes |
| Lid cut-away | reveals interior mechanism or spatial aggregation |
| Fill/group-by-pattern | demonstrate periodic pattern, count, partition, layered classification |
| Ground comparison strips | compare quantities at same origin and scale |
| Direct attribute swap | one change violates the invariant or shows phase/category change |
| Still hold/comparison frame | inspect, correct or recap a rule |

## Scale and legibility

R2 teaching review of an object-leading isometric sequence found the original distant scene too small. On future KLPs the active **complete teaching grouping** should occupy roughly 35–45% of frame height where practical, always ≥⅓ in key shots. If the individual items carry meaning, ensure each silhouette and ordering can be distinguished at 1080p, not only that the platform is large.

Reserve annotation lanes first, then project/position the object grouping with explicit bounds. Do not put class/shape/number words directly atop the subject "because a diagram already has text". Keep previous and current labels from colliding as animation crosses states. Headers, brackets, outlines and arrows are part of the no-overlap geometry. Check camera endpoints as well as the central reading frame. Main subjects are never cropped when read.

## Sampling and sound

Everything is a pure function of absolute time. Deterministic simulation is sampled with interpolation, not re-made each frame, and teleports/intersections checked frame by frame. Frame positions and labels must stay in the same clock. Action easing, on-ground text arrival and directive mark share one action start with VO.

Narration concise, action first. Subtitles on pale separate bottom strip; only one cue at a time. Restrained soft piano/vibraphone/percussion and genuine/recorded licensed local foley can support order and place, under speech. No reference demo score or dialogue. Target −14 to −16 LUFS, true peak ≤−1.5 dBFS. Full-speed media review is distinct from metadata/loudness statistics.
