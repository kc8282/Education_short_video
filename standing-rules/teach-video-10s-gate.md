# Teaching short-film 10-second gate

Adapted from Kevin's 2026-11-06 standing rule for educational samples.

## Hard order

1. **Segments:** produce approximately 10-second reviewable previews; the rendered interval may be a range from the one shared timeline, not a separately improvised clock.
2. **Evidence:** each interval includes its actual MP4 (or equivalent motion preview), **≥2 actual key frames**, narration audio or mixed VO, hash, BRIEF/Must mapping, and short segment README. Critical transitions need closer frame strips.
3. **Reviewer:** COO or designated human gate personally views the frames and listens to VO against teaching intent, the selected SKILL Musts, zero overlap, wrong labels, occlusion, residual marks and changed geometry. Producer self-checks cannot stand in for this.
4. **Explicit continuation:** only a written **「段过」/segment approved** from that gate opens the next segment. If not approved, revise the same segment and review again. Many proposals in one segment or a 40-second S1 are not permitted.
5. **Full film:** assemble/re-render from the shared final timeline, check actual A/V codec/decode/hash and then personally watch full speed with audio. A concatenation step alone is not a full-film audit. Gate keeps `FULL-GATE.md` empty until filled externally.
6. **No PASS shortcut:** no producer says PASS, teacher-approved, hand-writing-approved, or student-tested based on software checks. Kevin's first look is a separate later decision.

## Producer handoff

- segment / exact paths and file SHA / dimensions, fps and duration
- what changed and which Must is being demonstrated
- ≥2 chosen frames, contact sheet if useful, voice text and actual measured VO timing
- known issues and explicit "not claiming PASS"
- `COO-GATE.md` empty for reviewer; actual reviewer name/date/decision kept out of producer prefill

The rule prevents obvious problems reaching the final viewer; it does not guarantee teaching suitability, factual correctness or broad learner effectiveness.
